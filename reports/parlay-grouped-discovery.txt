Unified All Props / Trending Props discovery

Both screens now use the same grouped query, web table/navigation component, and native table/navigation component. The view parameter changes per-selection eligibility only. Existing Home/other screens retain their layouts.

Primary navigation: All Props, Passing, Rushing, Receiving, Touchdowns, Kicking, Defense, Game Specials. Only categories and secondary markets with actual supported available records are offered. Shared data-driven facets keep navigation consistent between views; an empty Trending subset does not invent qualifying records. Unsupported Game Specials/Receiving TD/etc. are not displayed merely because they appear in the configuration.

Groups are keyed by event, player, period and specific market. Anytime TD is distinct from numeric total-touchdown markets. Eligibility, book/odds filters and selection deduplication run before ranking/grouping. Highest-score group ordering uses the highest eligible selection. Standard lines lead; when absent, the best eligible alternate leads with an explicit label. Other standard sides and alternate thresholds expand beneath the lead. Every row preserves exact market ID, sportsbook, line, side, price, score and history. Counts show groups and selections separately; server pagination uses 12 complete groups.

Desktop/mobile web: reusable PropMarketNavigation and PropDiscoveryTable; responsive cards use the same row data/actions, with no wide-table horizontal scroll on small viewports. Primary categories scroll horizontally and the secondary selector stays compact. Native: corresponding React Native components, shared grouping/facets/formatting, existing SectionMenu for secondary navigation. Both expose score help and independent Add actions. Compatible web filters persist through sessionStorage; native screen switches retain current filters. Existing bet-slip persistence remains unchanged.

Trending hero/top-three actions preserved on web; native featured actions use the same endpoint results. No Lab Score model changes, transfer changes, provider generation requests or production writes.

Read-only local verification: Receiving -> Receptions, Trending, Alt Lines enabled, max odds -400 returned 22 eligible selections in 15 groups. First page contained 12 complete groups / 18 selections. Chris Olave's group kept the 6.5 standard line (score 81) as the primary row while ranking by its highest eligible score of 86. Two other sampled groups also retained standard primary lines.
