Parlay Lab breadcrumb navigation — implementation report

Implemented on All Props and Trending Props, in desktop/mobile web and the
shared React Native screen used by Android/iOS.

Behavior
- Root shows only primary categories. The secondary dropdown has been removed.
- Selecting a category replaces primary categories with a two-level breadcrumb
  and horizontal secondary market pills. All markets in that category are
  selected immediately.
- Selecting a market filters the existing grouped table without adding a third
  breadcrumb level. Red active pills also use bold/underline selection cues.
- All Props in the breadcrumb clears only category/market. Existing filters,
  sorting, alternate-line preferences and slip state remain independent.
- Available pills reuse database facets and the existing market taxonomy.
- Web uses URL category/market as authoritative state, supports refresh and
  browser history, and preserves category/market in the discovery screen links.
- Native uses Expo route parameters on the current screen (setParams), avoiding
  stacked copies of Parlay Lab. Both native discovery views share navigation.
- Narrow layouts scroll pills horizontally with selected-pill visibility.
  Native tap targets are at least 44px. Web supplies focus outlines, pressed
  states and a logical focus target when the selected category button disappears.

uses that component in both All Props and Trending Props. Taxonomy and URL

Limitations
Browser tests use isolated fixtures and mocked routing/API responses. They are
not a production end-to-end or real sportsbook transfer validation. Android/iOS
device builds and device accessibility checks were not performed. Native browser
previews do not establish Android/iOS device parity.

No production database updates, provider API calls, scoring/eligibility changes,
or sportsbook transfer enablement were performed for this navigation task.
