# Down & Distance — Rookie Blueprint Card Pack

Place the uncompressed folder at:

`public/assets/down-distance-rookie-blueprint-card-pack`

This follows the exact same production model as Injury Report, Contract Update, Developing Story, and Trade Talk:
- one neutral background
- editable HTML text
- currentColor SVG accents
- team accent via CSS
- no player images
- no team logos

Important: the included draft badge is generic and intentionally avoids the NFL shield/logo.
