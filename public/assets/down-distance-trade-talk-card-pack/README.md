# Down & Distance — Trade Talk Card Pack

Place this folder at `public/assets/down-distance-trade-talk-card-pack`.

Use the same shared card framework as Injury Report, Contract Update, and Developing Story. The background stays neutral; `TRADE TALK`, arrows, accent bar, and optional bottom strip use the runtime team accent via `currentColor` / `--card-accent`. All visible text stays HTML. Do not use player photos or team logos.

Important: SVGs loaded via `<img>` do not inherit page `currentColor`; use the same inline SVG / React component / mask method already working for the other cards.

`reference.png` is reference only, never production art.
